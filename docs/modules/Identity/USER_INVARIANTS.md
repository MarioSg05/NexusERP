# User Invariants

## Siempre deben cumplirse

- Todo usuario debe tener un nombre.
- Todo usuario debe tener un apellido.
- Todo usuario debe tener un correo válido.
- El correo debe ser único.
- La contraseña nunca se almacena en texto plano.
- Todo usuario debe tener un identificador.
- Todo usuario inicia activo.
- Todo usuario registra fecha de creación.
