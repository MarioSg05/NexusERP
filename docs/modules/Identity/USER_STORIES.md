# Sprint 1 - Identity

## ID-001 Registrar Usuario

### Historia

Como administrador quiero registrar usuarios para que puedan acceder al sistema.

### Acceptance Criteria

- El correo debe ser único.
- La contraseña nunca se almacena en texto plano.
- Todo usuario inicia activo.
- Debe registrarse fecha de creación.
- Debe registrarse el creador.
