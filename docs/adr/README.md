# Architecture Decision Records

This directory contains the architectural decisions that define the
engineering standards and significant technical choices of NexusERP.

## ADR Index

- ADR-001 - Use SQL Server
- ADR-002 - Rich Domain Model
- ADR-003 - Project Architecture
- ADR-004 - Aggregate Lifecycle Standard
- ADR-005 - Value Object Standard
- ADR-006 - Application Layer Pattern
- ADR-007 - Entity Framework Core Standard
- ADR-008 - Testing Standard
- ADR-009 - Read Query Strategy
- ADR-010 - Dashboard Composition Strategy
- ADR-011 - Reliable Asynchronous Messaging

Each ADR records a long-term architectural decision, its context and the
trade-offs accepted by the project.
